CLASS COUNTDOWN SCHEDULER
Experiment No. 11

AIM
To use JavaScript timers (setTimeout and setInterval) and
ES6 modules (import/export) to build an interactive class
countdown scheduler with real-time updates.

TECHNOLOGIES USED
1. HTML5
2. CSS3
3. JavaScript ES6
4. JavaScript setInterval()
5. JavaScript setTimeout()
6. ES6 import/export modules
7. HTML5 Canvas API
8. localStorage
9. requestAnimationFrame()

FEATURES
1. Bulk class scheduling.
2. Individual class selection.
3. Countdown timer with Start and Pause controls.
4. Resume and End Session functionality.
5. Automatic completion notification.
6. Canvas fireworks animation.
7. Session history.
8. Scheduled and completed session statistics.
9. Local storage for persistent data.
10. Responsive layout.

HOW TO RUN
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if necessary.
3. Right-click index.html.
4. Select Open with Live Server.
5. Add classes using the bulk scheduler.
6. Select a class and start the countdown.

IMPORTANT
Run the project using a local development server because
the application uses JavaScript ES6 modules.

RESULT
A responsive Class Countdown Scheduler demonstrating
JavaScript timers, modules, DOM manipulation, localStorage,
and Canvas animation.
