# 📝 To-Do List

A simple and interactive **To-Do List web application** built using **HTML, CSS, and JavaScript**.

This project allows users to add, edit, and delete tasks dynamically. It also demonstrates DOM manipulation, event handling, and basic JavaScript functionality.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔢 Automatic task counter
- ⌨️ Add tasks using the Enter key
- 📭 Empty task list message
- 🎨 Clean and responsive user interface
- 🖼️ Custom background image
- 📱 Responsive design for smaller screens

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and DOM manipulation
